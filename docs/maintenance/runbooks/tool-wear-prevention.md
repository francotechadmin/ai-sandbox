# Tool wear failure: prevention

- Replace tools on a fixed interval of 180 min of cutting time, below the 200 min risk zone.
- Review any machine whose average torque trends upward week over week.
- Keep coolant concentration and flow within specification; poor cooling shortens tool life.
- Track wear by machine quality type (L, M, H). Low quality (L) variants wear faster under the same load.
- Keep spare tools of the correct grade at the machine.
