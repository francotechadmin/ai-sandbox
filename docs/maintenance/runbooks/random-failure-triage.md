# Random failure: triage

Failure code RNF. In the equipment data random failures happen with a probability of about 0.1 percent per cycle, independent of the readings, so the sensor values will usually look normal.

## Steps
1. Check the other failure modes first. If tool wear, heat, power or overstrain conditions are present, the failure is not random.
2. If all readings are inside their limits, treat it as random.
3. Look for external causes: power dip, vibration from nearby equipment, operator error, a loose connector.
4. Check the controller event log around the time of the failure.
5. Restart and watch the next cycles.
