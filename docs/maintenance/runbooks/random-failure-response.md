# Random failure: response checklist

1. Record the time, the full set of readings and the machine state.
2. Lock out and visually inspect connectors, sensors and wiring.
3. Reseat or replace any connector that looks loose or corroded.
4. Restart the machine and run three test cycles.
5. If the failure repeats within a day, it is not random: escalate for a wider fault search.
6. Record the event so repeated random failures on one machine can be spotted.
