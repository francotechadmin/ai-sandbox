# Overstrain failure: prevention

- Alert at 85 percent of the limit for the machine type: 9,350 minNm for L, 10,200 for M, 11,050 for H.
- Replace tools earlier on machines that run high torque.
- Prefer H type machines for the heaviest cuts; L types have the least margin.
- Review cutting parameters when a new material is introduced.
- Check clamping and holder condition at each tool change.
