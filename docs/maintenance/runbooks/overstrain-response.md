# Overstrain failure: response checklist

1. Stop the cycle and lock out the machine.
2. Replace the worn tool (see the tool wear replacement procedure); this lowers the wear term at once.
3. Inspect the spindle, bearings and holder for strain damage, heat discolouration or play.
4. Check the workpiece for movement in its clamping.
5. Reduce depth of cut or feed so torque stays lower on restart.
6. Run a test part and recompute tool wear x torque against the limit for the machine type.
7. Record the event and the readings.
8. If the same machine repeats, escalate for a mechanical inspection.
