# Tool wear failure: replacement procedure

1. Complete lockout/tagout before touching the spindle or tool holder.
2. Remove the worn tool and keep it for inspection; note its minutes of use and part count.
3. Clean the holder taper and seat. Contamination here causes runout and fast wear.
4. Fit a new tool of the specified grade and torque the clamp to the tool maker's value.
5. Reset the tool wear counter to 0 min in the controller.
6. Run one test part, measure it, and confirm torque is back to its normal range before returning to production.
7. Log the replacement with the wear reading at removal.
